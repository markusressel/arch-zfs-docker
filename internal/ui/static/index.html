Upstream Kernel Synchronization

Queries official Arch Linux package data (linux and linux-lts) directly from the Arch Linux official API (archlinux.org/packages/.../json/). Polled automatically every 6 hours, or immediately via the Check Upstream Now button. When a new kernel is released upstream, a build job is dispatched to compile matching ZFS modules and update the repository index.

Client Configuration: Add this repository to your /etc/pacman.conf:
[zfslocal] Server = ...
